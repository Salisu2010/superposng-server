RepairMasterPro Token Generator (RMP)

Format: RMP1|PLAN|YYYYMMDD|DEVHASH16|SIG12. Activate Online will save/bind the device on the server (no token paste needed). In the app: Activation → set Cloud URL → tap Check Online Activation (you can leave token empty) or paste token and activate.

Online Activate: Use ANDROID_ID then click Activate Online. In the app, you can press Check Online Activation even with empty token to auto-activate.

Activate Device

Workflow: customer sends you Device ID → you paste token + deviceId → Activate. Customer app clicks “Check Online Activation”.

StayMasterNG Token Generator (STMN)

Use STMN2 Device Code
From app: Activation → Copy Device Code

Formats: STMN1|PLAN|YYYYMMDD|DEVHASH16|SIG12 or STMN2|PLAN|YYYYMMDD|DEVHASH16|SIG12 (Anti-Clone).

StayMasterNG: Activate Device (Online)

This will bind the token to the device online (like SuperPOSNG / RepairMasterPro). Customer app then taps Activate Token or Start Trial with internet.

Merge Shops

Use this when a user mistakenly created a new shop or changed phone/device. Select the From shop (data will be moved) and the To shop (kept).

Notes: This will move products, staff, sales, debtors, payments, devices, licenses, and pair codes from From into To. The old shop remains in the database but is marked as merged.
